# AidFlow AI

> **A Unified, Autonomous, AI-Powered Infrastructure for Transparent Donations & Disaster Relief**

AidFlow AI is a production-grade humanitarian infrastructure that transforms donations and disaster relief into transparent, autonomous, and verifiable financial workflows. By combining Artificial Intelligence, Blockchain, programmable wallets, cryptographic auditing, and rule-based automation, AidFlow AI ensures every contribution is traceable from donor intent to real-world impact.

---

## Problem

Traditional donation and disaster relief systems suffer from:

- Lack of transparency after donations
- Delayed relief distribution
- Human dependency and manual approvals
- Fund leakage and corruption
- No end-to-end audit trail
- Limited donor visibility into real-world impact

Current platforms collect funds, but very few can prove how they were actually used.

---

## Solution

AidFlow AI replaces trust-based humanitarian execution with a programmable, AI-driven infrastructure where policies define fund allocation, AI automates workflows, blockchain guarantees auditability, and programmable wallets enforce purpose-bound spending.

The platform transforms humanitarian intent into transparent, verifiable, and accountable financial execution.

---

# Why AidFlow AI?

Unlike traditional fundraising platforms, AidFlow AI is designed as a humanitarian execution infrastructure.

It combines:

- Artificial Intelligence
- Blockchain
- Cryptographic Auditing
- Rule-Based Policy Engine
- AI Agents
- Dynamic Trust Scoring
- Programmable Relief Wallets

into one unified platform.

---

# Key Features

## Transparent Donation Tracking

Track every donation from contribution to beneficiary.

---

## AI-Powered Decision Engine

Multiple AI agents automate:

- Eligibility Verification
- Fraud Detection
- Risk Assessment
- Workflow Automation

---

## Blockchain Audit Layer

Every critical event is hashed, organized into Merkle Trees, and anchored on-chain, providing immutable auditability without exposing sensitive information.

---

## Programmable Relief Wallets

Funds can only be spent for approved categories such as:

- Food
- Medicine
- Shelter

preventing misuse before it happens.

---

## Multi-Role Platform

Supports:

- Donor
- NGO
- Government
- Beneficiary
- Merchant
- Administrator

---

## Dynamic Trust Engine

Trust is computed using evidence instead of reputation.

Organizations earn credibility through verifiable impact rather than brand recognition.

---

## Real-Time Public Audit

Anyone can verify donation history without requiring NGO approval.

---

## Disaster Relief Automation

Supports AI-assisted emergency response through policy-driven automated workflows.

# Quick Start

Clone repository

```bash
git clone <repository-url>

cd AidFlow
```

Install dependencies

```bash
npm install
```

Start backend

```bash
npm run dev
```

Start workers

```bash
npm run workers
```

For the complete local setup, environment configuration, Redis, AI agents, and blockchain deployment, refer to the documentation below.
